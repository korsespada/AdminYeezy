# AI-каталог через Cockpit Tools

Раздел `/admin/seo-ai` обрабатывает опубликованные товары из Rails CRM. Production-сервер не обращается к `localhost` пользователя: он хранит очередь, а локальный worker на Windows вызывает Cockpit Tools и возвращает черновик.

## Возможности

- одиночные и массовые задания до 500 товаров;
- явный лимит товаров для каждой массовой партии;
- выбор по бренду, категории, подкатегории, гендеру и статусу;
- анализ старого текста и структурированных характеристик;
- contact sheet до 9 фотографий в сетке 3×3;
- второй проход по оригинальным кадрам для бирок, OCR и таблиц размеров;
- название, описание, H1, SEO title/description и alt-тексты;
- гендер только при уверенном результате;
- характеристики только из активного реестра Rails;
- предложение существующей или новой подкатегории без изменения верхней категории;
- конфликты с объяснением и уверенностью;
- сравнение старого и предложенного значения;
- компактная очередь с превью, ссылкой на storefront и раскрытием подробностей;
- русские названия характеристик и значений при сохранении технического кода мелким шрифтом;
- секундомер партии и среднее время обработки одного товара;
- пауза, продолжение, отмена и повтор ошибок;
- ручное применение отдельных полей и ограниченное автоприменение.

Модель и новая подкатегория никогда не применяются автоматически. Гендер, зарегистрированные характеристики и существующая подкатегория допускаются к автоприменению только при уверенности от 90%.

## Настройка production API

В окружении Rails API задайте длинный случайный токен:

```env
AI_CATALOG_WORKER_TOKEN=replace_with_a_long_random_value
```

После деплоя выполните миграции Rails. Токен не передаётся браузеру и не хранится в репозитории.

## Настройка локального worker

В `.env.local` AdminYeezy задайте:

```env
RAILS_API_URL=https://api.yeezyunique.ru/api/v1
AI_CATALOG_WORKER_TOKEN=the_same_value_as_on_rails
COCKPIT_API_URL=http://localhost:50943/v1/chat/completions
COCKPIT_API_KEY=agt_codex_...
COCKPIT_MODEL=gpt-5.6-luna
AI_CATALOG_WORKER_POLL_MS=5000
AI_CATALOG_WORKER_MAX_IMAGES=9
AI_CATALOG_WORKER_CONCURRENCY=10
AI_CATALOG_MEDIA_HOSTS=static.yeezyunique.ru,xcimg.szwego.com
```

Запуск:

```powershell
npm run ai:catalog-worker
```

Один опрос очереди для проверки настроек:

```powershell
npm run ai:catalog-worker -- --once
```

Если компьютер выключен, queued-задания остаются в Rails. Если worker оборвался во время обработки, lease истечёт через 10 минут и задание будет выдано повторно. После трёх неудачных попыток оно получает статус `failed` и может быть повторено из админки.

Worker держит до `AI_CATALOG_WORKER_CONCURRENCY` одновременных заданий. Конкретная массовая выгрузка дополнительно ограничивает параллельность выбранным в интерфейсе значением от 1 до 10; меньший из двух лимитов имеет приоритет.

## SEO и артикул

AI не добавляет артикул в название, H1 и SEO title. `seo_article` остаётся стабильным идентификатором, участвует в точном поиске и показывается отдельной строкой на странице товара.

Бренд выводится отдельно. Рекомендуемая структура:

```text
Название: Укороченный топ с кулиской
H1: Укороченный топ Prada с кулиской
SEO title: Укороченный топ Prada с кулиской | YeezyUnique
```

Фраза «в исполнении высокого качества» разрешена только в описании и не более одного раза. Слова «лучший», «оригинал», «официальный», «премиальный» и «трендовый» запрещены промптом.
