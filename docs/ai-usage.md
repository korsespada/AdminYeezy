# Использование ИИ

Вкладка `/admin/ai-usage` («Выгрузки» → «Использование») показывает, сколько
токенов и денег ушло на запросы к моделям. Данные копятся с момента выкладки
этой функции; более ранние запросы не учтены.

## Как ведётся учёт

- Каждый ответ модели (и каждая неудачная попытка) пишется строкой в
  `yu_scraping.ai_usage_events`. Запись делают сами транспорты:
  `lib/openrouter.ts` (OpenAI-совместимые провайдеры: OpenRouter, BYESU,
  DeepSeek и др.), `lib/anthropic.ts` и `lib/byesu.ts`. Поэтому учитываются все
  разделы, а не только «Выгрузки».
- Привязка к выгрузке, запуску, товару и поставщику берётся из контекста
  (`withAiUsageContext` в `lib/ai-usage.ts`, `AsyncLocalStorage`). Обработка
  товара выгрузки (`processOpenRouterItem`) ставит `feature = batch_ai`; другие
  вызовы помечаются `usageFeature`: `card_updates`, `chromoff`, `david_studio`,
  `measurement_templates`, `provider_test`. Остальное попадает в `other`.
- Токены разбираются из `usage` ответа (`lib/ai-usage-pricing.ts`):
  - OpenAI-совместимый: `prompt_tokens`, `completion_tokens`, кэш —
    `prompt_cache_hit_tokens` (DeepSeek) или `prompt_tokens_details.cached_tokens`,
    размышления — `completion_tokens_details.reasoning_tokens`;
  - Anthropic: `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`.
- Стоимость считается в момент запроса и хранится в `cost_usd`; задним числом
  не пересчитывается. Источник (`cost_source`):
  1. `provider` — провайдер сам вернул `usage.cost` (OpenRouter);
  2. `custom` — ручная цена модели из «Настроек ИИ» (`ai_providers.pricing`,
     USD за 1 млн токенов: вход, вход из кэша, выход);
  3. `builtin` — встроенный прайс DeepSeek.
  Без цены запрос учитывается в токенах, а в сумме помечается `*`.
- Ошибка записи учёта не прерывает обработку: она только пишется в лог.
  В тестах (`NODE_ENV=test`) запись отключена.

Таблица создаётся миграцией `scripts/migrate-ai-usage.js`
(`npm run db:migrate:ai-usage`), которая выполняется при старте контейнера.

## Что показывает вкладка

- Итоги за период (сутки, 7, 30, 90 дней, всё время): стоимость, средняя
  стоимость товара выгрузки, токены входа и выхода, доля входа из кэша.
- Подсказки: доля токенов размышлений, сколько потрачено в часы пик DeepSeek и
  сколько стоило бы вне пика, неудачные запросы, среднее время ответа.
- По дням, по выгрузкам (товары, запросы, кэш, стоимость, стоимость на товар),
  по поставщикам (средняя цена товара — по ней можно оценить новую выгрузку),
  по моделям и по разделам админки.

«Товар» — уникальная пара выгрузка + товар, по которому были запросы. Цена на
товар включает повторы, проверки фото и согласование цветовых семей.

## DeepSeek

Модель `deepseek-flash` принимает фото (JPEG, PNG, GIF, WebP, в том числе
`data:`-URL), поддерживает JSON-ответ и автоматический кэш префикса. Запрос
выгрузки уже собран под кэш: эталоны, визуальные примеры и общий промпт идут
первыми, данные товара и его фото — последними, поэтому общая часть у
соседних товаров читается из кэша.

Подключение: «Настройки ИИ» → «Добавить AI-провайдера», Base URL
`https://api.deepseek.com/v1`, ключ из кабинета DeepSeek, модель
`deepseek-flash` (или выбрать из `/models`). Цены DeepSeek встроены
(в пик, USD за 1 млн токенов):

| Модель | Вход | Вход из кэша | Выход |
| --- | --- | --- | --- |
| `deepseek-flash` | 0.30 | 0.006 | 1.20 |
| `deepseek-v4-pro` | 1.32 | 0.044 | 3.96 |

Вне часов пик всё вдвое дешевле. Пик — будни 01:00–04:00 и 06:00–10:00 UTC
(04:00–07:00 и 09:00–13:00 МСК); китайские праздники, когда тоже действует
скидка, не учитываются, поэтому в праздник расход будет показан с запасом.
Ручная цена в «Настройках ИИ» заменяет встроенный прайс и отключает учёт пика.
`deepseek-v4-pro` фото не принимает и для выгрузок не подходит.

По умолчанию DeepSeek работает в режиме размышлений; токены размышлений
оплачиваются как выход и видны во вкладке отдельно. Они входят в лимит
«Максимум токенов»: на тяжёлой карточке размышления заняли 6920 из 8000
токенов, и JSON-ответ оборвался. Такой ответ (`finish_reason = length` или
`stop_reason = max_tokens`) теперь отклоняется с ошибкой «Ответ ИИ обрезан
лимитом…» и не сохраняется. Раньше парсер вытаскивал из обрывка отдельные
поля, и товар помечался обработанным только с категорией и ценой. Для DeepSeek
лимит нужно держать с запасом (например, 20000).

В «Настройках ИИ» у провайдеров DeepSeek и OpenRouter есть список «Размышления
модели» (`ai_providers.reasoning_mode`): «По умолчанию провайдера» (`default`,
параметр не передаётся; у DeepSeek это уровень high), «Без размышлений»
(`disabled`) и уровни `low`, `high`, `max`. Для DeepSeek `disabled` отправляет
`thinking: {type: "disabled"}`, а уровень — `thinking: {type: "enabled"}` и
`reasoning_effort`. Для OpenRouter `disabled` отправляет
`reasoning: {enabled: false}`, а уровень — `reasoning: {effort}` (`max` у
OpenRouter передаётся как `high`). При размышлениях DeepSeek игнорирует
temperature. Для других шлюзов выбора нет:
неизвестный параметр они могут отклонить. Режим читается при старте запуска
обработки, поэтому уже идущий запуск доработает с прежним режимом.
